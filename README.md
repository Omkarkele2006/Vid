# Vid

## AI-Guided Adaptive Kernel Runtime Intelligence Framework

Vid is an AI-guided framework designed to improve Linux kernel fuzzing by dynamically adapting fuzzing strategies based on runtime feedback.

## Project Structure

- `src/` – Core Vid implementation
- `kernel/` – Linux kernel configuration and patches
- `syzkaller/` – Syzkaller configuration and integration
- `experiments/` – Baseline and Vid experiments
- `tests/` – Testing
- `scripts/` – Utility and automation scripts
- `dashboard/` – Result visualization
- `docs/` – Technical documentation
- `results/` – Experimental results
